# Cübidek website

Complete editable export of the Cübidek landing page (published version 39).

## Upload to GitHub

1. Extract `cubidek-website.zip` on your computer.
2. Open your GitHub repository and choose **Add file → Upload files**.
3. Upload the extracted contents, keeping `index.html`, `styles.css`, `app.js`, and the `assets` folder together at the repository root. Do not upload only the ZIP.
4. Commit the uploaded files.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select your branch and **/ (root)**, and save. GitHub will show the website address when publishing completes.

## Preview locally

Open `index.html` in a browser. No installation or build step is required.

## Files

- `index.html`: page content and structure
- `styles.css`: styles, layouts, and animations
- `app.js`: animated dashboards, industry switching, and navigation behavior
- `assets/`: supplied images and artwork, including earlier design assets
- `.nojekyll`: tells GitHub Pages to serve the static files directly

The site is a front-end concept with illustrative accounting data. It does not contain a working accounting backend. Google Fonts requires an internet connection; a system font is used if unavailable. No credentials or Sites hosting configuration are included in this export.
